# Smart Survey

Smart Survey 是一个基于 Vue 3、TypeScript 和 Vite 构建的本地问卷系统。它覆盖问卷创建、编辑、发布、填写、进度保存、数据分析和数据导出等基础流程，适合作为前端问卷应用原型、课程项目或轻量级本地调查工具。

当前版本使用浏览器 `localStorage` 存储数据，不依赖后端服务。

## 功能概览

- 问卷管理：创建、编辑、复制、删除、发布、关闭。
- 问卷编辑：支持题目增删改、拖拽排序、必答设置、选项配置、评分配置、矩阵配置。
- 题型支持：单选题、多选题、填空题、多行文本、评分题、矩阵题、排序题。
- 填写体验：逐题填写、进度条、题目导航点、必答校验、保存进度。
- 高级设置：随机题目、随机选项、关闭时间、条件显示、条件隐藏、条件跳转。
- 自定义校验：最小长度、最大长度、正则表达式、数值范围。
- 数据分析：回收数量、完成率、题目数量、选择题图表、评分分布、矩阵分布、排序平均名次、文本回答预览。
- 数据导出：JSON 和 CSV。

## 快速开始

安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

预览构建结果：

```bash
npm run preview
```

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 问卷列表与管理入口 |
| `/create` | 编辑器 | 创建新问卷 |

## 数据模型

主要类型定义在 `src/types/survey.ts`：

- `Survey`：问卷主体，包含标题、描述、题目、设置、状态、创建时间和更新时间。
- `Question`：题目主体，包含题型、标题、选项、校验规则、逻辑规则和题型配置。
- `SurveyResponse`：问卷回答，包含问卷 ID、答案映射和提交时间。
- `SurveySettings`：问卷设置，包含保存进度、进度条、随机题目、随机选项和关闭时间。

## 本地存储

项目使用浏览器 `localStorage` 保存数据：

| Key | 内容 |
| --- | --- |
| `smart-survey-list` | 问卷列表 |
| `smart-survey-responses` | 问卷回答列表 |
| `smart-survey-progress-{surveyId}` | 指定问卷的未提交填写进度 |

提交问卷成功后，对应的填写进度会被清理。

## 问卷状态

| 状态 | 值 | 说明 |
| --- | --- | --- |
| 草稿 | `draft` | 可编辑，不能填写 |
| 已发布 | `published` | 可填写，若设置关闭时间则需未过期 |
| 已关闭 | `closed` | 不能继续填写 |

填写页和提交逻辑都会校验问卷状态，避免通过直接访问 URL 提交草稿或已关闭问卷。

## 题型说明

| 题型 | 标识 | 说明 |
| --- | --- | --- |
| 单选题 | `radio` | 从多个选项中选择一个 |
| 多选题 | `checkbox` | 从多个选项中选择多个 |
| 填空题 | `input` | 单行文本输入 |
| 多行文本 | `textarea` | 多行文本输入 |
| 评分题 | `scale` | 在配置的分值范围内选择评分 |
| 矩阵题 | `matrix` | 按行列矩阵进行单选评价 |
| 排序题 | `sort` | 拖拽选项生成排序结果 |

## 条件逻辑

题目可以配置条件逻辑，当前支持：

| 操作符 | 说明 |
| --- | --- |
| `equals` | 答案等于指定值 |
| `not_equals` | 答案不等于指定值 |
| `contains` | 多选答案包含指定值 |
| `greater_than` | 数值答案大于指定值 |
| `less_than` | 数值答案小于指定值 |

支持的动作：

| 动作 | 说明 |
| --- | --- |
| `show` | 条件满足时显示题目 |
| `hide` | 条件满足时隐藏题目 |
| `jump` | 条件满足时跳转到目标题目 |

## 校验规则

除必答校验外，文本题和评分题可以配置自定义校验：

| 类型 | 说明 |
| --- | --- |
| `min_length` | 文本最小长度 |
| `max_length` | 文本最大长度 |
| `pattern` | 正则表达式匹配 |
| `range` | 数值范围，格式如 `1,5` |

## 数据分析与导出

分析页按题型展示不同结果：

- 单选题和多选题：选项占比图。
- 评分题：平均分和分布柱状图。
- 矩阵题：每行各选项选择分布。
- 排序题：每个选项的平均名次。
- 文本题：展示部分文本回答。

支持导出：

- JSON：包含问卷结构、回答数据和导出时间。
- CSV：适合表格软件继续处理。

## 当前限制

- 数据仅保存在当前浏览器，不支持跨设备同步。
- 没有用户系统、权限控制、团队协作和服务端 API。
- 问卷发布只是本地状态，不会生成可公开访问的线上链接。
- `dist` 目录目前存在于仓库中，是否继续提交构建产物需要根据部署方式决定。
- 分析页依赖 ECharts，构建时可能出现 chunk 体积提示。
